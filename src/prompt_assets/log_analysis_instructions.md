# Log Analysis Instructions

- Apply the critical decision rules.
- Inspect the available projects, sources, deterministic tools, mandatory guidance, and optional skill metadata.
- Review structured current evidence before history.
- Use `call_tools` only for evidence needed to satisfy the critical rules.
- Request only listed optional skills, and only when they can change interpretation of current evidence.
- Treat tool and skill inventories as capabilities, not evidence. Cite only evidence actually present.
- Do not infer live state or broad absence from windowed logs. Keep claims within the exact evidence scope.
- Return `final_report` only when the critical evidence gate is satisfied.
- Write analyst synthesis, not a family inventory; keep `watch_only` facts brief and subordinate.
